How Real-Time Sync Works
  • iOS: Firestore addSnapshotListener on parkingSpots fires on every document write — no polling, sub-second latency.
  • State transitions written to vehicleRecords with plate, floor, spot, and timestamp on every entry and exit event.
  • Validation method: occupied count from parkingSpots is cross-checked against the net event-log delta.
  • Queue: config/parking.queueLength is updated live by the admin app.
